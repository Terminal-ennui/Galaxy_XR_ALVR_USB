GALAXY XR ALVR USB — Beta 0.1 stable baseline

1. Get our stable-baseline Galaxy-XR-ALVR.apk from a successful GitHub Actions
   run. BUILD-INFO.txt must say ALVR 20.14.1. Do not use an older nightly artifact.
2. Download and extract the official Windows server:
   https://github.com/alvr-org/ALVR/releases/download/v20.14.1/alvr_streamer_windows.zip
   Release page: https://github.com/alvr-org/ALVR/releases/tag/v20.14.1
   Use our APK, NOT the upstream Android APK.
3. Download Windows Android platform-tools:
   https://developer.android.com/tools/releases/platform-tools
   Put platform-tools beside the APK and Connect-USB.ps1.
4. Enable headset USB debugging, connect its data port directly to a USB 3 PC
   port using a USB 3 data cable, wear it, and authorize your PC.
5. In PowerShell in the downloaded folder:
   .\platform-tools\adb.exe devices -l
   .\platform-tools\adb.exe install -r .\Galaxy-XR-ALVR.apk
   The device must say device, not offline or unauthorized.
6. Run:
   powershell -NoProfile -ExecutionPolicy Bypass -File .\Connect-USB.ps1
   Run this again after disconnecting USB or restarting ADB/PC/headset.
7. Open ALVR Dashboard.exe from the 20.14.1 server folder. Open ALVR Stable Test
   on the headset (package alvr.client.stabletest). Trust/add the physical headset
   with manual IP 127.0.0.1, select TCP, and start SteamVR from ALVR.
   The headset's displayed Wi-Fi IP is NOT the address to use for USB.
8. Start conservatively: HEVC, 72 Hz, 1440 x 1440 per eye, 60 Mbps target,
   8-bit SDR/HDR off; server and client foveation off. Change quality on the PC.

OWNER'S RTX 3090 UPPER SETTING
i7-11700K / RTX 3090 / NVIDIA 595.71:
HEVC, 72 Hz, 2560 x 2560 per eye, constant 375 Mbps target, 8-bit SDR,
HDR off, both foveation settings off, USB 3 + TCP.
The 60-second scene test averaged 315 Mbps of actual video with no reported
packet-loss counter increase. Reported client FPS averaged 63.6 and dipped;
this is NOT a locked-72-FPS or sustained-375-Mbps claim. Start at 200 Mbps
for more margin. Other rigs/games may need lower settings.

IF IT JITTERS
Restore the last working quality. Close the headset client, SteamVR, and the PC
ALVR dashboard, then reopen all three and rerun USB forwarding.
Do not keep increasing bitrate through judder.
Use the Windows local console, not active Remote Desktop.
For a SteamVR ALVR safe-mode block, exit SteamVR and run ALVR-Unblock.ps1.

SIGNING
CI uses an ephemeral debug key. A new build may not update an existing copy
signed differently. Do not uninstall a working app without saving its settings:
uninstalling deletes app data. This client is separate from alvr.client.dev and
the official stable app. The cleaned CI build needs its own headset acceptance.

This is compressed SteamVR streaming, not DisplayPort or a standalone PC OpenXR
runtime. No firmware/calibration changes are needed. Sleep/connection issues can
still occur. 10-bit/HDR/AV1/90 Hz are not claimed. No Wi-Fi comparison was made.
Read README.md, ACTIONS.txt and BUILD-PRIVACY.txt. Source patch: MIT.
