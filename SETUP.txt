Use our Galaxy XR client APK, not the upstream Android APK. Do not mix nightly
and stable clients/servers. Windows server modifications are not required.

The minimal client patch adds Android XR runtime access and Full Space metadata,
target SDK 35, a separate alvr.client.stabletest / ALVR Stable Test launcher,
72 Hz capability fallback, and a 1440-per-eye lobby for Galaxy XR.
The stable upstream decoder is retained. No experimental 10-bit, 90 Hz,
instrumentation, or Windows-driver patches are included.

Reproducible build: use the repository's Build Galaxy XR APK - Beta 0.2 Action.
It pins Rust 1.97.1, Android NDK 27.2.12479018, Java 17, target SDK 35,
cargo-apk revision and generic Khronos OpenXR loader 1.1.36.
See ci/build-apk.sh for the exact dependency setup, build and privacy audit.
The workflow checks out ALVR recursively at the pinned stable commit,
applies patches/galaxy-xr-client.patch and builds the release-mode debug-signed APK.
Output: dist/Galaxy-XR-ALVR.apk plus checksum and build provenance.
Keep signing keys private. Temporary CI signing does not provide stable update keys.

Install and USB setup: follow START-HERE.txt and README.md.
Recommended personal-rig settings and benchmark caveats are in README.md.
